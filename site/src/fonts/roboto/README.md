# Roboto

These unmodified variable TrueType fonts are vendored from the official Google
Fonts repository at commit `7085eb89a950e85db5b166b7a58d414544b4140c`. The upstream files are
`Roboto[wdth,wght].ttf` and `Roboto-Italic[wdth,wght].ttf`; only their filenames
were simplified. Both retain Roboto's normal/italic styles, weight axis 100–900,
default width 100, and the full upstream Unicode coverage, including Latin.

license. These files remain under that license.

An identical copy of the complete notice and license is also stored at
`site/public/licenses/Roboto-OFL.txt`, so the public assets distributed with
the Next build include the license for the bundled font files.
